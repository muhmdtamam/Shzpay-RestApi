SHZPAY API
Akses publik tanpa API key

Seluruh endpoint dapat langsung dipanggil tanpa autentikasi. Format permintaan: https://api.shzpay.biz.id diikuti /kategori/fitur, misalnya /download/tiktok?q=<link> atau /ai/gemini?text=<pesan>. Setiap respons memuat status, dev, dan credits. Batas 60 permintaan per menit per IP (status 429), dan status 502 berarti scraper sumber gagal memproses.
